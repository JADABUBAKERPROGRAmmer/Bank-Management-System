# Bank Management System - C++

A simple **Bank Management System** built using **C++**.

This project is a console-based application that allows the user to manage bank clients and store their information in a text file.

## Features

* Show all clients
* Add new clients
* Delete clients
* Update client information
* Find a client by account number
* Store client data in a text file
* Read and update data using file handling

## Client Information

Each client contains:

* Account Number
* Pin Code
* Name
* Phone
* Account Balance

## Technologies Used

* C++
* File Handling
* `fstream`
* `vector`
* `struct`
* Functions
* String Manipulation

## Data Storage

Client information is stored in:

`fileclientslist.txt`

The data is separated using the delimiter:

`#//#`
